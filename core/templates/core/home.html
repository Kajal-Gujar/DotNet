Welcome to Django MVT Project

This is a Django project with MVT (Model-View-Template) architecture.

Available Apps:

  • Blog App - Manage blog posts
  • About Page - Learn more about this project

MVT Architecture Components:

  • Models: Define the data structure (e.g., Post, UserProfile)
  • Views: Handle the business logic and user requests
  • Templates: Render the HTML pages (like this one)
