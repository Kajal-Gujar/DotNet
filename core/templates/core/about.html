About This Project

This Django project demonstrates the MVT (Model-View-Template) architecture.

Project Structure:

  • myproject/ - Main project configuration
  • blog/ - Blog application with posts
  • users/ - User profile management
  • core/ - Core functionality and home pages

Features:

  • Multiple Django apps following MVT pattern
  • Models for data structure
  • Views for business logic
  • Templates for presentation
