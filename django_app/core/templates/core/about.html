About This Django Project

This is a basic Django project demonstrating the MVT (Model-View-Template) architectural pattern.

Project Structure

django_app/
├── manage.py              # Django management script
├── mysite/               # Project configuration
│   ├── settings.py       # Project settings (PostgreSQL config here)
│   ├── urls.py          # Main URL routing
│   └── wsgi.py          # WSGI configuration
└── core/                # Example app demonstrating MVT
    ├── models.py        # M - Model: Task model
    ├── views.py         # V - View: Business logic
    ├── urls.py          # URL routing for core app
    ├── admin.py         # Admin interface configuration
    └── templates/       # T - Templates: HTML files
        └── core/
            ├── base.html
            ├── index.html
            └── about.html

MVT Architecture Explained

  • Model (M): Defines the data structure. In this project, the Task model represents to-do items stored in the PostgreSQL database.
  • View (V): Contains the business logic. Views process requests, interact with models, and return responses.
  • Template (T): The presentation layer. Templates are HTML files with Django template language for dynamic content.

Technologies Used

  • Django 6.0: Python web framework
  • PostgreSQL: Relational database (configured but requires credentials)
  • psycopg2-binary: PostgreSQL adapter for Python

Key Features

  • ✓ PostgreSQL database configuration
  • ✓ Example Task model with CRUD operations
  • ✓ Django Admin interface for data management
  • ✓ URL routing and views
  • ✓ Bootstrap-like styling (inline CSS)
  • ✓ Ready for expansion with more apps and features
